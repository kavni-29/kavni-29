I like exploring how systems work, building practical tools, and making information easier to understand. These two projects reflect that curiosity in different ways.

<table>
  <tr>
    <td width="50%" valign="top">
      <p><sub>NETWORKS · ANALYSIS</sub></p>
      <h3><a href="https://github.com/kavni-29/netscope">NetScope ↗</a></h3>
      <img src="assets/projects/netscope-flow.svg" alt="Diagram: saved capture to flows, explainable rule checks, and report" width="100%">
      <p>A Python desktop and command-line tool for exploring saved PCAP/PCAPNG captures. It groups packets into bidirectional flows, summarizes endpoints and protocols, applies deterministic explainable anomaly rules, and exports reports.</p>
